# トイレスナイパー（試作）

男子トイレの小便器で、おしっこの的あてをする3DミニWebゲーム。スタートすると出はじめ、ドラッグで狙う。勢いはだんだん落ちていくので、狙いを上げて追いかけ、膀胱が空になる前に的へ合計で目標の時間だけ当てればクリア。ステージは無限に続き、クリアに3回失敗するまで遊べる。ゲームオーバーになると、クリアしたステージの数で称号が決まる。

- 視点は一人称で、便器を見下ろす。尿の出口はカメラのほぼ真下にあって画面の外に出ており、画面の下の端には自分のお腹（シャツ）だけが少し映る。体は映さない。
- 見た目はデフォルメ（アニメ調の陰影）。縦型 9:16 でスマホに合わせている。
- 1ステージは約15〜20秒（水を流す演出を除く）。URL に `?stage=N` を付けると、確認用に N ステージ目から始められる。

## 遊び方

1. 「あそぶ」→ ステージ1の開始画面 →「スタート」で出はじめる（途中で止められない）
2. 画面のどこでもドラッグして狙う。なぞった分だけ狙いが動く（上 = 遠く、下 = 近く、左右 = 左右）
3. 的に当たっている間だけ「命中」のゲージがたまる。目標の秒数に届いたらクリア。クリアしたあとも、当てた分だけ秒数と得点が増える
4. 膀胱が空になると、水を流す（ボタンが押され、奥の面を水が流れ落ちて、受け皿で渦を巻いて排水口へ）。ハエがいるステージでは、水が流れるとハエはどこかへ飛んでいく。水が引いたら結果が出る
5. クリアしたら次のステージへ。失敗するとライフ（♥）が1つ減り、同じステージをやり直す。3回失敗したらゲームオーバーで、称号と合計得点が出る
6. 開始画面の「やめる」で途中でやめられる（1ステージでも遊んでいれば、ゲームオーバーと同じ結果画面を出す）

## 得点と称号（仮の値。遊びながら調整する）

- 1ステージの得点 = 的に当てた秒数 × 100点（0.1秒刻み）＋ クリア 200点 − こぼした量 × 10点/ml。0点より下がらない。
- こぼれは得点だけに関わり、クリアには関係しない。最後のポタポタ（数滴）は狙っても止められないので数えない。
- ベストの得点とクリア数は端末に保存し（`localStorage` の `toilet-sniper:best`）、タイトルにはベストの得点と、今までで一番多くクリアしたときの称号を出す。
- 称号はクリアしたステージの数で決まる。遊んでいる間は出さず、ゲームオーバー（またはやめたとき）の画面と、タイトルのベストにだけ出す。途中の結果画面には称号も次の称号も出さない。

| クリア数 | 称号 |
|---|---|
| 0〜5 | はじめてのトイレ |
| 6〜10 | トイレ初心者 |
| 11〜15 | トイレ中級 |
| 16〜20 | トイレのベテラン |
| 21〜30 | トイレのスナイパー |
| 31〜40 | トイレの上級スナイパー |
| 41〜50 | トイレの天才スナイパー |
| 51〜99 | トイレの神スナイパー |
| 100〜 | トイレの神様 |

## ステージ

はじめの8ステージは手で作ってある。9ステージ目からは、組み合わせで作る（`src/stages.ts`）。

| # | 名前 | 的 | ひねり |
|---|---|---|---|
| 1 | まんなかの的 | 奥のシール | |
| 2 | ちいさな的 | 高い位置の小さなシール | |
| 3 | 消臭剤をねらえ | 受け皿の消臭剤 | がまんの限界: 勢いが強い（3.8m/秒、30ml/秒） |
| 4 | うごく的 | 左右に動くシール | |
| 5 | とまったハエ | ハエ1匹 | 1.6秒当て続けるとピョンと逃げる |
| 6 | あるくハエ | 歩くハエ1匹 | 当てると慌てて速く歩き、2.2秒で逃げる |
| 7 | ハエが3びき | ハエ3匹 | 量がやや多い（300ml）。0.9秒で飛び立ち、別の場所に止まる |
| 8 | ラストスナイプ | 歩くハエ2匹 | 量が少ない（230ml）、手ぶれ2倍 |

- 9ステージ目から: 的（奥のシール・動くシール・消臭剤・止まるハエ・歩くハエ・ハエの群れ）と勢い（ふつう・がまんの限界・ちょびっと）を、ステージ番号から作る乱数で選ぶ。同じステージは誰が遊んでも同じ中身。ステージが進むほど、的が小さく（最大で3割）、ハエが逃げやすく、手ぶれが大きくなり（最大で約2.3倍）、ハエのステージが増える（25ステージ目で上限）。
- ハエは飛んでいる間は当たらない。止まる場所は、奥の面の低め（高さ0.47〜0.7m）か受け皿の奥寄り（手前のふちに水流が引っかからない範囲）。

### 目標の秒数の決め方（`computeGoal`）

目標の秒数は手で決めず、ステージを始める前に計算する。

1. 「人に近いプレイヤー」（0.3秒遅れで反応し、狙いを動かす速さに上限がある。`HUMAN_SIM`）に3回遊ばせ、いちばん少なかった当てた時間を取る。
2. それに割合を掛ける。割合はステージ1で 0.55、ステージが進むほど上がって 0.92 に近づく（`GOAL`）。
3. 狙いを固定したままでいちばん長く当てられる時間（的の方向ごとに、上下の角度を0.1刻みで調べる）より、0.8秒以上長くする。
4. 0.5秒刻みに丸める。人に近いプレイヤーでも届かない組み合わせは、別の組み合わせで作り直す。

計算は自動プレイを数十回回すので重い（スマホで最大1秒ほど）。画面が止まらないよう Web Worker（`src/stageWorker.ts`）で行い、次のステージはプレイ中に先に作っておく。

`tests/stages.test.ts` で、1〜30ステージについて次を確かめている。

- 1ステージが約15〜20秒で終わる
- 0.3秒遅れで追いかければクリアでき、こぼれは10ml未満
- 何もしない・狙いを固定したまま（左右5通り×上下31通り）ではクリアできない

反応の遅れを変えた仮のプレイヤーで、3回失敗するまでにクリアできたステージの数（`tools/sim/seeds.test.ts`）: 遅れ0.2〜0.3秒なら30ステージ全部、0.4秒で29、0.5秒で8、0.6秒で3。

- 2026-10-22: 操作を「どこでもドラッグ」だけにし、スティックと操作の切り替えをなくした。便器の手前を丸くした。

- 2026-10-22: 8ステージと★の評価をやめ、無限ステージ（3回失敗で終わり）、得点、称号にした。1ステージを約15〜20秒にするため、標準の量を 350→260ml にし、最後のポタポタを約1.7秒から約0.5秒に縮めた（`dribbleMl` 6→2.5ml）。目標の秒数は計算で決めるようにした。
- 2026-10-23: 称号のしきい値を 0〜5 / 6〜10 / 11〜15 / 16〜20 / 21〜30 / 31〜40 / 41〜50 / 51〜99 / 100〜 にし、「トイレの天才スナイパー」を足した。称号はゲームオーバーの画面だけに出し、途中の「称号アップ」と次の称号の案内をやめた。結果画面のハートを消した。タイトルの一言を「狙って当てろ！」にした。

## 勢いの仕組み（`src/flow.ts`）

- 出口の速さ `v = vMax × sqrt(残量 / 最初の量)`、流量 `Q = qMax × sqrt(残量 / 最初の量)`。これで速さは時間に対してほぼまっすぐ下がる（トリチェリの式と同じ形）。
- 出はじめの約0.5秒は弱く、勢いが最大の25%を切ると途切れ途切れ（ポタポタ）になる。ポタポタは最後の数滴（`dribbleMl` 2.5ml）だけで、約0.5秒で終わる。
- 標準の値は、膀胱の量 260ml、最大の流量 25ml/秒、最大の速さ 3.2m/秒。本流は約16秒、全体で約17秒。
- 粒は出た瞬間の向きで飛ぶので、狙いを振ると水流がムチのようにしなる。

## 調整値（`src/config.ts`）

| 項目 | 場所 | 内容 |
|---|---|---|
| 便器・カメラ・お腹の位置 | `GEOM` | 見た目と当たり判定は同じ値を使う。便器は上から見て手前が半分の楕円（`frontRound`）で、丸い壁の当たり判定は楕円の柱との交わりで計算する |
| 勢い | `FLOW_DEFAULT` | 量・流量・速さ・ポタポタの量 |
| ドラッグの感度、狙える範囲、手ぶれ | `AIM` | |
| 水を流す演出の時間 | `FLUSH` | 出し終わってから押すまで、水が引くまで、ハエが飛んでいくまで |
| 得点 | `SCORE` | 1秒あたりの得点、クリアの得点、こぼれの減点 |
| ライフ | `LIVES` | 何回失敗したら終わりか |
| 称号 | `TITLES` | 称号と、必要なクリア数 |
| 目標の秒数の決め方 | `GOAL` | 割合の始まりと上限、固定の狙いとの差 |
| はじめの8ステージ | `STAGES` | 的の位置・大きさ。ステージごとに勢いを変えられる |
| 9ステージ目から | `src/stages.ts` の `generateTemplate` | 組み合わせの重み、難しさの上がり方 |

ステージ1の数値は、`tests/session.test.ts` と、調整用の測定 `tools/sim/*.test.ts`（`npx vitest run --config tools/sim/vitest.config.ts`）で次のように確かめた。

- 勢いに合わせて狙いを追いかけると約11秒当たる（目標6秒）。こぼれは0ml。
- 狙いを固定したままだと、いちばん当たる角度でも5.1秒でクリアできない。何もしないと約2.5秒。
- 1〜40ステージの中身と難しさの一覧は `tools/sim/endless.test.ts`（`N=60` などで数を変えられる）。

## 構成

```text
src/
  config.ts        調整値、はじめの8ステージ、得点・ライフ・称号
  flow.ts          膀胱と勢い
  physics.ts       狙いの向き、当たり判定、届く角度の計算
  stream.ts        尿の粒
  targets.ts       的とハエの動き（止まる・歩く・逃げる・飛んで止まる・水を流すと飛んでいく）
  session.ts       1回のステージ（当てた時間・こぼれ・クリア）。描画とは切り離してある
  run.ts           1回の通しプレイ（ライフ・得点・称号・ベストの保存）
  stages.ts        ステージの中身（9ステージ目からの組み合わせ）と、目標の秒数の計算
  stageWorker.ts   目標の秒数の計算を裏で行う Web Worker
  sim.ts           自動プレイ（人に近いプレイヤー・固定・何もしない）。目標の計算とテストで使う
  render/scene.ts  トイレ・便器・お腹・的
  render/fx.ts     水流の描画、しぶき、水たまり
  render/targets.ts シール・消臭剤・ハエの見た目
  render/flush.ts  水を流す演出（奥の面を流れ落ちる水、受け皿の渦）
  audio.ts         音（Web Audio で合成）
  main.ts          画面・操作・演出・確認用の入口 window.__game
tests/             単体テスト（vitest）
tools/e2e.mjs      ブラウザでの動作確認（playwright-core + インストール済みの Chrome）
tools/shots.mjs    画面の撮影
tools/ogp/make-ogp.mjs  OGP画像（public/ogp.png、1200×630）の生成
tools/promo/       告知動画の撮影と書き出し（scenario.js が台本、promo.css が見た目）
public/            favicon.svg と ogp.png（ビルドで dist/toilet-sniper/ 直下にコピー）
```

## 開発

```sh
npm install
npm run dev        # http://127.0.0.1:5195/
npm run dev:lan    # 同じ Wi-Fi のスマホから http://<このPCのIP>:5195/ で開ける
npm test           # 単体テスト
npm run e2e        # npm run dev を起動した状態で実行
npm run ogp        # npm run dev を起動した状態で、OGP画像 public/ogp.png を作り直す
npm run promo      # 告知動画を作る（ビルドしてから撮影。出力は ../video/）
npm run build      # dist/ を空にしてから dist/toilet-sniper/ に出力
npm run deploy     # ビルドして Cloudflare Workers に公開
GAME_URL=https://game.chozo.net/toilet-sniper/ npm run e2e   # 公開版の確認
```

## 告知動画

`npm run promo` で、縦型 1080×1920・約30秒の告知動画を作る。ゲームをヘッドレスの Chrome で1コマずつ撮り、字幕・効果文字・ズームを重ね、効果音と合成のリズムを混ぜて MP4 にする。

- 出力: `../video/toilet-sniper-promo.mp4`（本編）、`-cover.jpg`（表紙）、`-sheet.jpg`（2秒おきの一覧）。途中のファイルは `../video/work/`。動画はリポジトリに含めない。
- `PROMO_EVERY=15 npm run promo`: 15コマおきだけ撮って、構成を一覧画像（`-preview.jpg`）で確かめる。
- `PROMO_ENCODE_ONLY=1 npm run promo`: 撮り直さずに、書き出しだけやり直す。
- 構成: つかみ（ハエ3匹のステージをスローとズームで）→ タイトル「狙って当てろ！」→「男子トイレの便器で狙い撃ち！」（ステージ1でドラッグ）→ 的・消臭剤・動く的・ハエ・ハエの群れを次々に → 最後に水を流して（「ジャー！」）エンドカード。ゲーム画面は大きめ（`config.layout` の maxW 0.8 / maxH 0.76）に置く。
- 音: ゲームの効果音と、Web Audio で合成したポップなBGM（`tools/promo/stage.js` の `popMusic`。BPM 140、C→G→Am→F の進行に4つ打ち・手拍子・はずむベース・裏拍の和音・ピコピコのメロディ、最後の1.2秒でフェードアウト）。音源ファイルは使っていない。-14.3 LUFS、真のピーク -2.2 dBTP。どの音にも数msの立ち上がりを付けている。付けないと AAC に変換したあと真のピークが -1 dBTP を超える。
- ゲーム側の撮影用の入口（`window.__game`）: `manual` / `step` / `state` / `play` / `start` / `next` / `quit` / `touchDown` / `touchMove` / `touchUp` / `drainEvents` / `audio.capture` / `audio.drain` / `audio.render`。効果音はすべて `Sound.render(ctx, name, args, when)` を通るので、普段の再生と書き出しで同じ音になる。擬音の吹き出しは、ゲーム内の時間で0.8秒たつと消える。
